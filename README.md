# Share Load - File Transfer & Games

A powerful Android file-sharing and local network communication application.

## Key Features:

1. **Lightning Fast File Transfer (P2P):** Share files via Wi-Fi Direct (P2P) directly between devices without needing an internet connection. Just open the app, find nearby devices, and transfer at maximum speed.
2. **Local Network / Hotspot Connection:** Connect devices via a shared router or a mobile hotspot. You can easily start a Hotspot from the app which generates a **QR Code**. The receiving device just scans the QR code using any camera app to connect automatically!
3. **Web Share:** Share files with non-Android devices (like iOS, Windows, Mac) using a built-in web server. Select your files and open the provided URL on the target device's browser.
4. **Share Load Games (New!):** Play professional 2-player games directly over the connection while you transfer files!
   - **Chess (الشطرنج):** A real-time chess experience.
   - **Connect 4 (أربعة بربح):** The classic four-in-a-row strategy game.
   - **Tic-Tac-Toe (إكس أو):** Fast-paced fun.
   *All games sync instantly over the local connection as standalone experiences.*

## How to use:
- To transfer files, simply launch the app on both devices. Use the Hotspot QR Code or Wi-Fi Direct to link them up.
- To play games, navigate to the "GAMES" tab (ألعاب شير لود) after successfully establishing a connection.

Built using Kotlin, Jetpack Compose, and Netty.
