# Share Load - File Transfer & Games

A powerful Android file-sharing and local network communication application designed to give you the fastest, lightest, and easiest file transfer experience.

## Key Features:
1. **Lightning Fast File Transfer (P2P):** Share files via Wi-Fi Direct (P2P) directly between devices without needing an internet connection. Just open the app, find nearby devices, and transfer at maximum speed.
2. **Local Network / Hotspot Connection:** Connect devices via a shared router or a mobile hotspot. You can easily start a Hotspot from the app which generates a **QR Code**. The receiving device just scans the QR code using the in-app scanner to connect automatically!
3. **Phone Clone (One-Click Transfer):** Transfer your entire phone (Apps, Images, Videos, Audios) with a single click using the "Clone Phone" option in the top menu.
4. **Web Share:** Share files with non-Android devices (like iOS, Windows, Mac) using a built-in web server.
5. **Share Load Games:** Play professional 2-player games directly over the connection while you transfer files!
   - **Othello (Reversi / عطيل):** The classic strategy game of flips and captures.
   - **Connect 4 (أربعة بربح):** The classic four-in-a-row strategy game.
   - **Tic-Tac-Toe (إكس أو):** Fast-paced fun.
   *All games sync instantly over the local connection as standalone experiences.*
6. **Optimized Dark Mode:** Deep, pure black dark mode optimized for OLED screens to save battery.
7. **In-App Instructions:** Read the localized Arabic and English usage instructions right from the app settings menu.

## How to use:
- To transfer files via Hotspot, one device starts the Hotspot. The other device clicks **Scan to Connect**, scans the Hotspot's QR Code, and both devices will automatically transition to the sending screen without leaving the app!
- To clone your phone, tap the three dots in the File Transfer screen and select **Clone Phone (استنساخ الهاتف)**.
- To play games, navigate to the "GAMES" tab (ألعاب شير لود) after successfully establishing a connection.
